# Ruang Pengajar + ukuran kertas dan tata letak diagram

## Pasang
1. Supabase → SQL Editor → jalankan `supabase/12_ruang_pengajar.sql` (sekali; setelah 11).
2. Unggah isi paket ke GitHub, tunggu deploy Ready. Tidak ada variabel baru.

## Ruang Pengajar (Kelola Kelas → Ruang Pengajar)
Hanya pengajar dan admin yang bisa melihat dan memakainya.
- **Perpustakaan:** simpan bahan materi dan kitab rujukan sebagai berkas (PDF, Word, PowerPoint, Excel, TXT, JPG, PNG; maks. 30 MB) atau tautan (Google Drive, situs, YouTube). Ada pencarian dan penyaring jenis (Kitab/referensi, Bahan materi, Lainnya). Penambah dapat menghapus miliknya; admin dapat menghapus semuanya.
- **Diskusi:** buka topik, lalu berbalas pesan di kotak dialog (Ctrl+Enter untuk kirim). Halaman memuat ulang otomatis tiap 15 detik. Pengajar mendapat notifikasi HP saat ada topik baru, dan pembuka topik mendapat notifikasi saat ada balasan.
- Berkas disimpan di penyimpanan privat dan dibuka lewat tautan sementara (5 menit).

## Diagram
- Ukuran kertas: A4 dan F4/Folio, potret dan lanskap (150 dpi; kualitas HD = 300 dpi). Penilai kenyamanan memakai satuan poin cetak.
- Tata letak baru: **Bawah ke atas** (akar di bawah, cabang naik ke atas).
